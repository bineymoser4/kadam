# Qadam

Qadam — компактный сайт готовности к поступлению для старшеклассников и студентов, с проверкой плана наставником.

## Главная логика

- Без регистрации и паролей: на входе выбираешь роль — **Ученик** или **Ментор**.
- **Ученик** вводит GPA, SAT/ОРТ, IELTS/TOEFL, бюджет, уровень, страну, направление, дедлайн, портфолио и желаемый вуз. Поле можно оставить пустым — модель не подставляет вместо него случайное число, а честно понижает уверенность в оценке.
- Сайт показывает шанс поступления как диапазон с уровнем уверенности, сильные и слабые стороны и три действия с наибольшим эффектом на шанс.
- «Создать план» формирует задачи по слабым местам и отправляет их **ментору** на утверждение. После утверждения ученик отмечает задачи доказательствами (текст/ссылка), а ментор принимает их или просит доработать.
- Раздел «Стипендии» — вручную проверенный список международных программ с пометкой «нужно проверить» там, где точный порог или дедлайн года меняется и не используется в подсчёте шанса.
- Поиск работает по кыргызстанским, региональным и международным университетам; сохранённые вузы можно сравнить и выгрузить статистику в CSV.

## Почему это полезно

Студенту не нужно угадывать, куда подаваться и что подтягивать. Qadam показывает, что мешает поступлению, а ментор подтверждает прогресс — это не просто трекер, а проверяемый план.

## Структура кода

- `src/scoring/` — движок подсчёта шанса (`engine.ts`) и его веса (`config.ts`). Нет констант-заглушек: недостающий показатель исключается из среднего и понижает уверенность, а не поднимает шанс.
- `src/data/` — профиль ученика, роль и данные планов/задач/менти, хранятся в `localStorage` без бэкенда.
- `src/scholarships/` — список стипендий и честная проверка критериев (гражданство/уровень — да/нет, язык/дедлайн — всегда «уточнить»).
- `src/university/` — нормализация данных вузов из `src/constants.ts`.
- `src/student/`, `src/mentor/`, `src/entry/` — экраны по ролям.

## Запуск

```bash
npm install
npm run dev
```

После сборки:

```bash
npm run build
npm start
```

## Проверка

```bash
npm run lint
npm run test
npm run build
```

## Демо-данные

Данные ментора и учеников живут в `localStorage` (`kadam-plans-v1`). Кнопка «Сбросить демо» в кабинете ментора возвращает исходные демо-профили.
