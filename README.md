# Kadam

Kadam — компактный сайт готовности к поступлению для старшеклассников и студентов.

## Главная логика

- Пользователь вводит GPA, SAT/ОРТ, IELTS/TOEFL, бюджет, страну, направление, дедлайн, портфолио и желаемый вуз.
- Сайт показывает шанс поступления, сильные стороны, слабые места и персональный план.
- Поиск работает по кыргызстанским, региональным и международным университетам.
- В карточках есть фото кампуса через `imageUrl`; если фото нет, показывается аккуратный placeholder.
- Характеристика профиля показана диаграммой и короткими действиями.
- Сохранённые вузы можно сравнить и выгрузить статистику в CSV.

## Почему это полезно

Студенту не нужно угадывать, куда подаваться и что подтягивать. Kadam сразу показывает, что мешает поступлению: академическая база, английский, финансы, портфолио, дедлайны или fit с программой.

## Запуск

```bash
npm install
npm run dev
```

После сборки:

```bash
npm run build
npm start
```

## Проверка

```bash
npm run lint
npm run build
```
